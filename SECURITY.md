# Security Policy

## Supported Versions

Only the latest commit on the `main` branch is actively maintained with security updates and bug fixes.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| Older releases   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in **Media Tray Control**, please report it responsibly:

1. **Do not create a public issue** on GitHub.
2. Send an email describing the vulnerability to **monway+1@users.noreply.github.com** or use GitHub's private vulnerability reporting feature under the **Security** tab if available.
3. Include clear steps to reproduce the issue, details about the environment/OS, and any proof-of-concept scripts or logs.

### Response Timeline

* **Initial response:** Within 48 hours acknowledging receipt of the report.
* **Status update:** Within 7 days with an assessment or mitigation plan.
* **Fix & disclosure:** Once a fix is validated and committed to `main`, an advisory will be published.
