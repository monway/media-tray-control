# Contributing to Media Tray Control

Thank you for your interest in improving **Media Tray Control**.

## How to Contribute

### Reporting Bugs
* Check existing issues first to avoid duplicates.
* If not found, open a new issue with clear steps to reproduce, expected behavior, and your OS/environment details.

### Suggesting Enhancements
* Open an issue describing the feature, why it is useful, and how it should work.

### Submitting Pull Requests
1. Fork the repository and create a branch from `main`.
2. Keep changes focused and well-documented.
3. Test your changes locally to ensure the tray icon and service control operate cleanly.
4. Submit a pull request referencing any relevant issue.

## Code of Conduct

This project follows the [Code of Conduct](CODE_OF_CONDUCT.md). Please treat everyone with respect.
